# 面试展示与手机体验验收（2026-11-11）

## 检查发现与修复

1. 原先个人贡献较概括，工作归属和技术决策不够醒目。现在将“我的工作”放在详细试听前，明确上游网络与本项目的数据/训练/评估/流式交付范围；每项工作可以直接查看对应证据。
2. 增加公平对照、任意分块流式状态、噪声来源泛化三个可展开的难点。分别说明问题、处理和验证，不把架构复现写成原创网络。
3. 单片段相对输入的增益容易与 E4 相对 E3c 的批量结果混淆。试听前明确区分两种基线；目标三种子、来源级 seed17 检查、原官方集负结果分开解释。
4. 旧详情把非零小误差显示成 0.000。现在 5.133450031280518e-6 显示为 5.13e-6，真实零与缺失值分别显示为 0.000 和“无法确认”；只改变显示，不改数值。
5. 手机媒体控件原有 5 像素高的进度输入、22–36 像素的图标按钮。现在触摸区域至少 44 像素高；加入四入口底部导览，档案分类改为换行全部可见。弹窗说明表格可左右滑动，并保留可见关闭入口。

## 实际浏览器操作

对象为 Edge 中的本机生产预览。以下是实际操作结果，不是静态 DOM 推断的通过标记：

- 主内容顺序为本人工作 → 技术难点 → 实验结果 → 详细试听 → 流式工程 → 验收边界。
- 三个难点可独立展开，另一项自动收起。流式难点显示 192 组及 5.13e-6；其按钮可打开对应报告与证据。Escape 关闭后焦点回到原按钮，展开状态保留。

# 白色视觉更新（2026-11-11）

本次遵循用户最终选择的白色主调，取代此前未发布的深色尝试。保留现有项目内容、真实波形试听、实验档案与证据边界。

## 实现

- 全站采用纯白、炭黑、浅灰细线，深蓝用于波形与选中状态。首屏、导航、图表、档案、弹窗和手机底部导航同步更新。
- 首屏重排为项目标题、简短职责和真实音频试听台，统一按钮、留白、字号和数据文字层次。
- 波形概览由冻结极值数据聚合到最多 144 个显示分段；输入、增强和参考共用幅值尺度。新增实际时长的五个时间刻度与幅值范围说明，没有模拟电平。
- “播放中 / 待播放”来自播放器实际状态，不代表模型或设备验收结果。
- 手机保留 44 像素操作区域、换行实验筛选、底部导览、局部滚动表格和固定关闭入口；手机隐藏重复规格行以缩短首屏。

## 验证范围

- TypeScript、生产构建和 10 项测试通过；冻结快照身份核验通过。
- 13 组批次、3 个案例、9 个 WAV、39 个原公开资源、模型身份和历史实验数值不变。
- 本轮浏览器控制接口异常，无法完成新配色的可视截图和手机视口复查。不能沿用旧配色截图作为本轮视觉通过证据；本版浏览器视觉验收标为待验证。
- 真实手机试听、声卡、实时麦克风和原 Sites 云端闭环没有新增通过结论。

发布后以只读 HTTP 检查和编译包身份核对确认上线内容。具体报告保存在被 Git 排除的 `outputs/`。

## 实现

- 石墨黑首屏、明亮正文、蓝色强调，替换原来的配色和卡片堆叠；加强标题、留白、次要文字与键盘焦点层次。
- 首屏三种场景使用已批准 WAV。波形来自冻结的真实极值数据，以共同尺度聚合到最多 96 个显示分段；不使用随机装饰波形。
- 两处试听保留 A/B 切换位置；互斥播放，避免同时发声；异步切换时清除另一播放器待恢复的播放状态。
- 单独说明复现、同父状态/同预算对照、三种子复验、增量 STFT 和 ONNX Runtime 流式交付。
- 实验档案改为可筛选行列表。全部 13 组仍可访问，保留 DNSMOS 失败和恢复记录、原官方集负结果及证据下载。
- 弹窗支持 Escape、焦点约束、关闭后焦点恢复和滚动锁定。窄屏表格局部滚动，不撑宽整页。
- 手机布局将播放操作放在概览波形前，使 390×844 视口首屏可直接操作。

## 实际验收

自动检查：TypeScript / 生产构建、8 项测试、冻结资源身份核验通过。13 批次、3 案例、9 WAV 及模型身份保持不变。

Edge 浏览器实际操作（本机生产预览）：

- 4 秒 WAV 元数据可读，无媒体错误；播放能实际推进到结尾。
- 将进度定位到 0.8 秒，切换增强输出后保留 0.8 秒位置。
- 启动另一播放器后原播放器暂停；暂停后两处音频均停止。
- 键盘、风扇、干净人声可切换。干净对照保留数值上限和“不计算提升量”提示。
- 完整对比区可切换实际波形与三轨同色标时频谱。
- “失败与恢复”筛选显示两项，DNSMOS v1 显示两次失败及无质量结论；全部档案显示 13 项。
- 三种子详情同时保留 +6.143 和 −0.239 dB、两处证据链接；Escape 关闭后焦点回到触发按钮。
- 390×844 下导航、弹窗和试听可用；320×700、390×844 的文档宽度等于客户区宽度，没有全局横向溢出。
- 页面控制台只观察到浏览器扩展来源错误，没有观察到同源应用错误。
